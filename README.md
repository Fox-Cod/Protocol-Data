# Protocol-Data

База законов серверов **Majestic RP** для справочника
[Protocol](https://github.com/Fox-Cod/Protocol): кодексы, законы и правила
проекта всех 19 серверов в JSON.

> [!IMPORTANT]
> **Это копия правил с официального форума Majestic RP, а не первоисточник.**
> Тексты законов написаны администрацией и авторами форума Majestic RP и
> принадлежат им. База собрана автоматически, поэтому в ней возможны ошибки
> разбора: обрезанное название статьи, неверная нумерация. Если сомневаетесь —
> сверяйтесь с форумом. Проект фанатский и с разработчиками Majestic RP не связан.

## Что внутри

| Файл | Что это |
|---|---|
| `data/<сервер>.json` | все документы одного сервера: Конституция, кодексы, законы |
| `data/rules.json` | общие правила проекта (форум, организации, ограбления, захваты…) |
| `data/manifest.json` | список наборов и дата сборки базы |
| `manifest.json` | копия `data/manifest.json` для удобства |

Серверы: Atlanta, Boston, Chicago, Dallas, Denver, Detroit, Houston,
Las Vegas, Los Angeles, Memphis, Miami, New York, Orlando, Phoenix, Portland,
San Diego, San Francisco, Seattle, Washington.

На 31.10.2026 в базе около 32 000 статей, все файлы весят 35 МБ.

## Формат

### `manifest.json`

```json
{
  "updated": "2026-10-31T21:22:59Z",
  "date": "2026-10-31",
  "servers": {
    "orlando": { "file": "data/orlando.json", "codes": 35, "size_kb": 1970, "date": "2026-10-31" }
  }
}
```

`updated` — время сборки базы. Protocol обновляет свою базу, когда это время
новее, чем у него. Набор, которого нет среди 19 серверов (как `rules`),
приложение показывает в разделе «Правила проекта».

### `<сервер>.json`

Объект документов: ключ — короткий id документа (`uk`, `pk`, `ak`…), значение —
сам документ.

```json
{
  "uk": {
    "id": "uk",
    "short": "УК",
    "title": "Уголовный кодекс",
    "parts": [
      {
        "title": "КОДЕКС",
        "chapters": [
          {
            "title": "Глава XII. Преступления против общественной безопасности",
            "articles": [
              { "num": "12.8", "title": "★★★★ (F/R) Незаконный оборот оружия или спец. средств.", "parts": [
                { "n": "ч. 1", "t": "Незаконное приобретение, передача, сбыт, перевозка…" }
              ] }
            ]
          }
        ]
      }
    ]
  }
}
```

Вложенность всегда одна: `parts → chapters → articles`, у статьи —
`{num, title, parts: [{n, t}]}`. **`num` — строка**: номера вроде `12.8` и `1.9.1`
числом не записать. Поля `sub`, `icon`, `color`, `glow` — для оформления в приложении.

Тексты лежат так, как написаны на форуме, вместе со служебными пометками
форума — например, звёзды `★` и `[Региональная]`. Protocol убирает их при
показе, а в базе они остаются: так текст совпадает с форумом.

## Откуда берётся и как часто обновляется

Базу собирает парсер форума Majestic RP. Перед каждой отправкой сюда автор
смотрит сводку изменений: сколько статей стало в каждом наборе, что пропало,
что появилось. Обновляется по мере изменений на форуме. Историю видно в
[коммитах](../../commits/main).

Пользователи Protocol получают обновления кнопкой «Обновить базу» в
приложении, ничего качать отсюда руками не нужно.

## Если хотите использовать базу сами

- **Своя сборка Protocol из исходников** — сделайте форк этого репозитория и
  поднимите свою раздачу базы по инструкции
  [servers/README.md](https://github.com/Fox-Cod/Protocol/blob/main/servers/README.md).
  Сервер раздачи автора в своих сборках использовать нельзя.
- **Свой проект** — формат выше, файлы читаются как обычный JSON. Помните,
  что тексты принадлежат Majestic RP, и указывайте форум как первоисточник.
